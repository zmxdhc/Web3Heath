# Web3Heath

Provides a simple web interface for tracking physical health metrics and monitoring vital signs in medical environments.

Web3Heath is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/Web3Heath.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Web3Heath is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
